Política de privacidad

Esta página explica cómo trata los datos el proyecto Agente de Feedback al revisar publicaciones, preparar calendarios y consultar fuentes públicas.

Proyecto y contacto

Esta política corresponde a Agente de Feedback en feedback-sigma-one.vercel.app. Para consultas sobre privacidad o sobre datos que gestione el proyecto, escribe a cimardilan@gmail.com.

Qué datos se usan y para qué

  • Perfil de marca: nombre, descripción, público, tono, colores, tipografías, reglas y referencias visuales para adaptar las revisiones y propuestas.
  • Contenido que aportas: textos, imágenes, láminas y manuales PDF seleccionados para analizar la marca o revisar una pieza. Las imágenes se procesan en el navegador antes de enviarlas.
  • Campañas: objetivo, público, fechas, región, preferencias, borradores, fuentes, estados y revisiones del calendario. Si aportas un histórico de métricas, se puede usar su resumen para sugerir formatos y horarios.
  • Consultas públicas: temas, hashtags, cuentas profesionales, canales y páginas de referencia. Las fuentes pueden devolver textos, autores, enlaces, fechas y métricas públicas disponibles.
  • Acceso: si el proyecto exige un código compartido, el navegador lo guarda y lo envía al propio servidor para autorizar solicitudes. No es tu contraseña de Facebook.

Dónde se guardan

En tu navegador: se guardan la configuración y miniaturas de referencia de la marca, las preferencias y calendarios locales, el histórico importado cuando se usa y el código de acceso. Se utiliza almacenamiento local del sitio; estos datos pueden seguir ahí al cerrar la pestaña. El PDF seleccionado se envía al analizarlo, pero este flujo no lo guarda como archivo persistente del proyecto.

Si usas la interfaz local conectada a producción, sus solicitudes se procesan en el mismo servidor que el sitio público y sus campañas compartidas se guardan allí. Los datos del navegador local y los del dominio público siguen separados.

En el servidor: las campañas compartidas, referencias y hallazgos pueden guardarse en almacenamiento privado de Vercel Blob cuando está configurado. El calendario puede guardarse automáticamente para el equipo al terminar una generación, además del guardado manual. Quienes tengan el código del equipo pueden acceder a los datos compartidos. En desarrollo se puede usar un archivo local privado del servidor.

Las consultas a proveedores también pueden permanecer temporalmente en cachés de memoria. No hay un plazo de eliminación automática configurado para las campañas y referencias persistentes. Borrar el navegador no borra las copias del servidor ni los archivos que hayas exportado.

Qué información reciben otros servicios

  • Google Gemini: el servidor envía los textos, imágenes, referencias y PDF necesarios para el análisis solicitado. Al generar o cambiar una publicación, puede enviar contexto de marca, público, objetivo, preferencias, resúmenes de métricas y fuentes consultadas para producir la respuesta.
  • Meta (Facebook e Instagram): las consultas de lectura envían identificadores de cuentas o páginas, hashtags o nombres profesionales y credenciales configuradas por el administrador en el servidor. Permiten recuperar contenido y métricas autorizados. Estas consultas no publican tus borradores ni envían tus imágenes o manuales de marca a Meta. La app no incorpora actualmente un inicio de sesión con Facebook para visitantes.
  • YouTube, Google Trends y GDELT: reciben los parámetros de búsqueda correspondientes, como tema, canal, país o período. El tema puede proceder de la descripción de campaña. Devuelven videos públicos, búsquedas generales o noticias para orientar las propuestas.
  • Cuentas propias, por separado: si el administrador las configura y solicita su lectura, existen conectores para Facebook, Instagram, TikTok y LinkedIn. Su contenido no se usa como tendencia competitiva del radar. TikTok queda pendiente en el radar y X está excluido de las consultas.
  • Vercel: aloja el sitio, ejecuta el backend y puede almacenar los datos compartidos. La infraestructura puede tratar datos técnicos de las solicitudes, como dirección IP y datos del navegador. La pantalla principal también solicita tipografías a Google Fonts.

El tratamiento y la conservación que hagan esos proveedores se rigen por sus condiciones y configuración. El proyecto no puede garantizar desde esta página el borrado de sus registros o copias. Puedes consultar las políticas de Google, Meta y Vercel.

Estado del acceso a Facebook

El radar de Facebook permanece pendiente de acceso a páginas públicas hasta que una consulta real devuelva publicaciones de una página que no administremos. Poder leer una página propia o tener credenciales no acredita ese acceso externo.

Cómo gestionar tus datos

Puedes borrar los datos del sitio en tu navegador y solicitar al contacto del proyecto la revisión o eliminación de los datos que controle. No hay una herramienta de borrado automático de campañas compartidas. La solicitud se revisa manualmente para identificar la información y comprobar que corresponde al solicitante; no se fija aquí un plazo ni se promete eliminar datos bajo control de terceros.

Consulta las instrucciones de eliminación de datos, que separan el borrado local, la desvinculación de Facebook y la solicitud al proyecto.
