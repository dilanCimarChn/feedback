Eliminación de datos

Borrar los datos del navegador, desvincular Facebook y pedir la eliminación al proyecto son acciones distintas. Sigue los pasos que correspondan a dónde se guardó tu información.

1. Borrar lo guardado en el navegador

  1. Si quieres conservar tu trabajo, exporta primero las configuraciones o calendarios que necesites. Borrar los datos locales elimina las copias guardadas en ese navegador.
  2. Cierra todas las pestañas de la aplicación Agente de Feedback antes de borrar los datos. Así, un guardado pendiente no volverá a escribir el borrador al cerrar. Puedes mantener abierta esta página de instrucciones, que no guarda datos.
  3. Abre la configuración de privacidad de tu navegador y busca los datos o permisos de sitios web. Localiza feedback-sigma-one.vercel.app. En navegadores que lo permiten, también puedes abrir esa configuración desde el icono junto a la dirección del sitio.
  4. Elige borrar o eliminar los datos de ese sitio, incluido su almacenamiento local. Los nombres de los menús varían según el navegador; borrar solo el historial de navegación no basta.
  5. Vuelve a abrir la aplicación después de borrar los datos. Repite el proceso en otros navegadores, perfiles o dispositivos donde lo hayas usado. Si utilizaste otra dirección del proyecto o una versión local, borra también los datos de esa dirección.

Esto elimina del navegador la configuración de marca y sus referencias visuales, los calendarios y preferencias locales, el histórico importado y el código de acceso guardado. No borra las campañas compartidas del servidor.

La opción «Restablecer» de la configuración solo borra la marca. No elimina por sí sola los calendarios ni el código de acceso. Los archivos JSON o CSV que descargaste se deben borrar aparte de la carpeta donde los guardaste.

2. Desvincular la app de Facebook

  1. Entra en Facebook con la cuenta con la que autorizaste la app. No necesitas enviar esa contraseña al proyecto.
  2. Abre Configuración y privacidad → Configuración y busca Apps y sitios web (también puede aparecer como «Aplicaciones y sitios web»).
  3. Busca Agente de Feedback, abre sus opciones y selecciona Eliminar. Revisa y confirma lo que indique Facebook. Si la autorización fue comercial, busca también en Integraciones comerciales o «Integraciones empresariales».
  4. Comprueba que la app ya no figure como activa. Puedes empezar desde Apps y sitios web de Facebook o Integraciones comerciales. Facebook puede pedirte iniciar sesión y cambiar la ubicación de estas opciones.

Si no aparece, puede que no hayas autorizado esta app con esa cuenta. La versión actual del sitio no ofrece un inicio de sesión con Facebook para visitantes; sus integraciones se configuran desde el servidor.

Desvincular no equivale a solicitar el borrado. Revocar el acceso en Facebook no borra automáticamente las copias locales, las campañas compartidas ni la información que el proyecto ya hubiera recibido. Para pedir su eliminación, sigue el paso siguiente.

3. Solicitar la eliminación al proyecto

  1. Escribe a cimardilan@gmail.com con el asunto Solicitud de eliminación de datos — Agente de Feedback.
  2. Indica qué quieres eliminar: por ejemplo, una campaña compartida, una referencia o datos recibidos mediante una cuenta autorizada. Incluye el nombre o identificador de la campaña y, si corresponde, el nombre o enlace público de la página o cuenta relacionada. Comparte solo lo necesario para localizar la información.
  3. El proyecto revisará la solicitud y, si hace falta, pedirá una aclaración para identificar los datos o comprobar que puedes solicitar su eliminación. Se te informará del resultado y de las limitaciones que se encuentren.

No envíes contraseñas, códigos de acceso, claves de API ni tokens. No se necesitan para presentar la solicitud.

El borrado de campañas, referencias y hallazgos almacenados por el proyecto se gestiona manualmente; no existe un botón de eliminación del servidor ni un plazo automático de retención. Esta página no promete un plazo fijo de respuesta o borrado.

Qué queda fuera de ese borrado

La solicitud se refiere a los datos bajo control del proyecto. No elimina publicaciones originales de Facebook, Instagram u otras plataformas, ni los archivos exportados o las copias que hayan guardado otros integrantes del equipo. Tampoco garantiza eliminar registros o copias de los proveedores como Meta, Google o Vercel; sus propios canales y políticas se aplican a los datos que controlan.

Para conocer qué se envía y dónde se almacena, consulta la política de privacidad.
